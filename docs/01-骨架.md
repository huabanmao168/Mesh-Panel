# 第 1 块：骨架

## 目标

把"主控"的最小可运行版本搭起来。**不装任何东西到节点**，只做三件事：

1. 后端进程能跑起来，前端能打开。
2. 能在前端添加 / 编辑 / 删除节点（IP / SSH 端口 / 用户名 / 密钥 或 密码）。
3. 点节点的"测试连接"按钮，主控用 SSH 连一下，回报"连得上"或"连不上 + 错误信息"。

跑通这三件事，第 1 块就算完。

## SSH 测试连接怎么实现

`backend/ssh/client.py` 里写一个函数：

```python
def test_connection(host, port, user, auth_type, password=None, private_key=None, timeout=8) -> tuple[bool, str]:
    """返回 (是否成功, 错误信息或 uname 输出)"""
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    try:
        if auth_type == "password":
            client.connect(host, port, user, password=password, timeout=timeout)
        else:
            pkey = paramiko.RSAKey.from_private_key(io.StringIO(private_key))
            client.connect(host, port, user, pkey=pkey, timeout=timeout)
        _, stdout, _ = client.exec_command("uname -a", timeout=5)
        return True, stdout.read().decode().strip()
    except Exception as e:
        return False, f"{type(e).__name__}: {e}"
    finally:
        client.close()
```

API 层调用它，把结果写回 `nodes` 表。

## 前端页面（本块就一个）

**节点列表页 `/`**：

- 顶部一个"添加节点"按钮
- 表格列：名称 / 地址 / 状态徽章 / 最后检查时间 / 操作（测试连接 / 编辑 / 删除）
- 添加 / 编辑用同一个对话框组件，字段：
  - 名称
  - 主机地址
  - SSH 端口（默认 22）
  - SSH 用户（默认 root）
  - 认证方式（单选：密码 / 私钥）
  - 根据上一项动态显示密码框或 textarea
- "测试连接"按钮点击 → 调 `/test` → 弹 Toast 显示成功/失败 → 刷新列表

样式走 Element Plus 默认，**不做任何美化**，能用就行。

## 开发跑起来的步骤（验收标准）

```bash
# 后端
cd /root/mesh-panel/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 前端（另一个终端）
cd /root/mesh-panel/frontend
npm install
npm run dev   # vite dev server，代理 /api 到 :8000
```

**第 1 块完工的标准**：
1. 浏览器打开 `http://主控IP:5173`，看到节点列表页（空表）。
2. 点"添加节点"，填一台真实可 SSH 的小鸡信息，保存，列表出现这条。
3. 点"测试连接"，几秒内状态变成绿色"reachable"，鼠标悬停能看到 `uname -a` 的输出。
4. 故意改错密码再测，状态变红色"unreachable"，能看到错误信息。
